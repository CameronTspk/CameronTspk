# 🚀 Featured Engineering Projects

## [Twin Rim-Driven Propulsor UAV Control System](https://github.com/CameronTspk/Rim_Driven_UAV.git)

**Aerospace Controls & Vehicle Systems**

Development of a small UAV architecture using **two independently vectored rim-driven propulsors** as the primary propulsion and control system.

The project investigates whether differential thrust and multi-axis thrust vectoring can provide practical control authority for a compact aircraft while reducing dependence on conventional aerodynamic control surfaces.

### Current Work

* Developing nonlinear **6-DOF aircraft dynamics models**
* Modeling actuator forces and moments from independently vectored propulsors
* Developing nonlinear **actuator-to-wrench mappings**
* Evaluating constrained control allocation under actuator saturation
* Comparing twin-propulsor and tail-assisted architectures
* Testing aggressive simultaneous translational and rotational commands
* Analyzing control authority, altitude loss, actuator saturation, and stability
* Developing MATLAB / Simulink simulation environments
* Investigating future PX4 / hardware-in-the-loop implementation

### Engineering Areas

`Flight Controls` `MATLAB` `Simulink` `6-DOF Dynamics` `Control Allocation` `UAVs` `Propulsion` `Systems Engineering`
